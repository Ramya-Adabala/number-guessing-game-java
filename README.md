\#  Number Guessing Game



A simple console-based \*\*Java game\*\* where the player tries to guess a randomly generated number within limited attempts.



\---



\# 📖 Description



The \*\*Number Guessing Game\*\* is a beginner-friendly Java project designed to practice:



\-  \*\*Variables and Data Types\*\*

\-  \*\*Loops and Conditional Statements\*\*

\-  \*\*Random Number Generation\*\*

\-  \*\*User Input Handling\*\*

\-  \*\*Basic Game Logic\*\*



The program generates a random number between \*\*1 and 100\*\*, and the user must guess the correct number.



\---



\#  Features



\-  \*\*Random number generation\*\*

\-  \*\*User-friendly console interaction\*\*

\-  \*\*Hints for incorrect guesses\*\*

&#x20;-  Too High

&#x20; -  Too Low

\-  \*\*Limited number of attempts\*\*

\-  \*\*Game Over message\*\*

\-  \*\*Winning message\*\*
